# Deepwalker

Мобильный браузерный прототип Action RPG в мрачном подводном фэнтези.

## Первый вертикальный срез

- Phaser 3 без сборщика: запуск через GitHub Pages или любой HTTP-сервер.
- Один персонаж — Глубинщик — с фиксированным экранным джойстиком.
- Тестовая карта подземелья с камерой, препятствиями и двумя противниками.
- Простое преследование, столкновения, урон и полоса здоровья.
- Ограничение delta time, отключённые lights/antialias и минимум объектов для стабильной работы на Android.

## Запуск

Откройте `index.html` через статический сервер или GitHub Pages. Для локальной проверки:

```bash
python -m http.server 8080
```

Следующий этап — заменить процедурные фигуры на утверждённые игровые изображения Глубинщика и добавить атаку/добычу после согласования визуальных ассетов и боевого UX.
