# BrowserGameRPG

Рабочий мобильный прототип вертикальной Action RPG «Глубинщик».

Запуск: откройте `index.html` через GitHub Pages или локальный статический сервер.

В версии есть вертикальный мобильный экран, виртуальный джойстик, Глубинщик в подводных руинах, автоматическая атака, способности, враги, здоровье, урон и смерть. Визуальный стиль основан на утверждённой концепции из проектного чата: глубоководное существо, панцирь, коралловые наросты, бирюзовое свечение и молот.
